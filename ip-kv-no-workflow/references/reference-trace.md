# 参考图传入与内部追溯

## 素材解析

读取references/catalog.json和references/asset-map.json，选中一个asset_id，并以skill根目录解析对应图片路径。检查文件存在，内部读取实际图片，确认内容与标签一致。记录本地文件SHA-256；不得编造图库原始URL。

平台接受本地图片时直接传该文件；只接受URL或素材ID时，将该文件上传为平台素材，再传上传返回的URL或素材ID。重传后URL不同不代表参考图不同。记录asset_id、本地相对路径、SHA-256、上传返回素材ID/URL及上传结果的对应关系。只有原始URL确实存在且可访问时才可直接使用；当前包仅包含本地图片，不要求提供不存在的原始URL。

## 每轮调用

- 分析：实际读取或传入选中的参考KV图片，记录使用方式及任务标识。
- 首轮A、B：图片输入必须包含选中参考KV与用户IP；文字输入为分析结果及内部规则。调用前核对实际参数中的文件、URL或素材ID与素材对应记录一致。
- 第二轮A、B：只以本分支中间图为编辑对象，记录parent_task_id或中间文件路径及其所属首轮任务，间接关联回同一asset_id。不得为让日志出现原始URL而改变第二轮输入。
- 兜底：两个直接生成请求均实际传入KV_026和用户IP，并记录对应素材。

每次调用内部记录stage、branch、reference_asset_id、实际图片输入及其角色、task_id、parent_task_id（适用时）、输出路径。任务无ID时记null并记录可核对的实际调用结果，不虚构ID。

## 核查与失败

工具返回生成结果后，根据实际调用参数和上传结果核查，不能仅凭Prompt或画面相似就断言使用过参考图。缺少图库文件、上传失败、图像工具不能接收参考图，均属于执行错误；停止受影响分支并文字说明，不转成无参考自由生成，也不将其当检索无匹配。未核实传入时标记未确认，不声称已使用图库。

全部记录仅内部保存，不预览图片、不向用户提供参考链接，不加入仅含两张最终成品的提交清单。
