# 执行图

```text
IP图、主标题、可选副标题及要求
  → 图库标题检索 → 未命中则业务/颜色/氛围匹配
  → 无合适参考：固定KV_026＋用户IP图＋用户文案
      → 最佳GPT图像模型分别直接生成A、B → 两张全部终检通过 → 统一交付两张16:9最终图片，各一次
  → 有参考：最高能力GPT模型分析（analyze.md）
  → 分析结果＋参考KV＋用户IP图，内部附加generate.md规则
     A：最佳GPT图像模型 → 中间图A → 文案编辑 → 最佳GPT图像模型 → 最终A
     B：最佳GPT图像模型    → 中间图B → 文案编辑 → 最佳GPT图像模型    → 最终B
  → 逐图终检：用户IP身份/头型比例/帽子状态＋主副标题逐字核对与整体垂直居中检查＋真实尺寸严格16:9
  → 两张均通过 → 提交清单仅含最终A、B → 一次统一交付，各展示一次
  → 任一未通过：内部修正对应分支后重新检查，不提前展示成功图
```

分析与图片生成均使用当前环境提供的最佳适用GPT能力；A、B表示候选版本，不要求两个不同型号。不把本说明当作真实调用已完成或验证成功的证据。

正常匹配路径与兜底路径互斥。兜底不执行最高能力GPT模型分析或双分支两轮生成，详见fallback.md。

参考图、中间图、返修图和分析稿只供内部读取与传递，不预览、不提供链接。两张均验收后统一交付，最终两张各展示一次，提交清单仅包含这两张成品。两条路径均严格继承图库字体设计并锁定用户IP头型与比例。
