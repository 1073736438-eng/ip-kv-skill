# IP KV生成

上传一张IP图片，输入主标题，生成两版16:9运营KV。副标题与其他要求可选，内置26张参考图库。

## 安装到Codex

将下面这句话发送给Codex：

> 帮我安装这个GitHub仓库中 ip-kv-no-workflow 目录下的skill：https://github.com/1073736438-eng/ip-kv-skill

安装后按Codex提示重新加载或重启以识别新skill。需要账号和环境提供可用的图片生成、参考图输入及编辑能力；skill不会额外提供模型权限。

## 使用示例

上传IP图片后发送：

> 使用ip-kv-no-workflow生成一张春节营销KV，主标题：安心过大年，副标题：暖心投稿赢好礼。

两张成品全部验收后统一交付；参考图和过程图仅在内部使用。隐藏过程图片的效果取决于运行平台是否支持。
